# PugaWhoIsTalking

A World of Warcraft Addon

## ENGLISH

PugaWhoIsTalking is a World of Warcraft addon that displays useful information about the players speaking in chat, using small icons next to their messages.

The icons show:

* **Class:** the player's class icon.
* **Race and sex:** the corresponding race icon.
* **Level:** the player's level, when available. A skull may appear instead of the level for much higher-level characters of the opposing faction.

Open **Options → AddOns → PugaWhoIsTalking** to choose which icons are displayed in each chat type, including whispers, say, yell, party, raid, instance, guild, guild officers, and other chat channels. Changes are applied immediately, and your preferences are shared across characters within the same WoW client.

**Level availability depends on your WoW version.** In WoW Classic Era, some players' levels may not be available, even when their class and race are known. This is a limitation of the game client, not an error in the addon.

PugaWhoIsTalking uses Blizzard's class and race icons and requires **PugaLib** for its configuration interface.

## DEUTSCH

PugaWhoIsTalking ist ein Addon für World of Warcraft, das nützliche Informationen über Spieler anzeigt, die im Chat schreiben. Kleine Symbole erscheinen direkt neben ihren Nachrichten.

Die Symbole zeigen:

* **Klasse:** das Klassensymbol des Spielers.
* **Volk und Geschlecht:** das entsprechende Volkssymbol.
* **Stufe:** die Stufe des Spielers, sofern verfügbar. Bei Charakteren der gegnerischen Fraktion mit deutlich höherer Stufe kann stattdessen ein Totenkopf erscheinen.

Öffne **Optionen → AddOns → PugaWhoIsTalking**, um für jeden Chattyp festzulegen, welche Symbole angezeigt werden. Dazu gehören Flüstern, Sagen, Schreien, Gruppe, Schlachtzug, Instanz, Gilde, Gildenoffiziere und weitere Chatkanäle. Änderungen werden sofort übernommen. Die Einstellungen gelten für alle Charaktere innerhalb desselben WoW-Clients.

**Ob eine Stufe verfügbar ist, hängt von deiner WoW-Version ab.** In WoW Classic Era lässt sich die Stufe mancher Spieler nicht ermitteln, selbst wenn ihre Klasse und ihr Volk bekannt sind. Dies ist eine Einschränkung des Spielclients und kein Fehler des Addons.

PugaWhoIsTalking verwendet die Klassen- und Volkssymbole von Blizzard und benötigt **PugaLib** für seine Einstellungsoberfläche.
